# CircuitBench Web

CircuitBench runs as a static web app. Its schematic compiler, model importer, waveform parser and trace expressions use the desktop Python core through Pyodide. ngspice 46 runs in a separate Web Worker for each simulation. The published artifact contains both runtimes and the model files. Circuit data, logs and waveforms stay in the browser unless you download them.

## Build and preview

On Windows, double-click **Start CircuitBench.cmd** in the `web` folder. With Node.js installed, it builds the app and opens [127.0.0.1:8765](http://127.0.0.1:8765/) in your browser. Keep the launcher window open while using the app. The first launch installs missing dependencies.

From the repository root, with Node.js 24 and npm installed:

```powershell
npm ci --prefix web --ignore-scripts
npm run build --prefix web
npm test --prefix web
node web/preview.mjs
```

Open [127.0.0.1:8765](http://127.0.0.1:8765/). The build copies the shared Python modules and models from the repository into `web/dist`. Use the local web address for preview so the browser can load the simulator workers.

## Publish on GitHub Pages

1. Push the web project and `.github/workflows/pages.yml` to the repository.
2. In **Settings → Pages → Build and deployment**, set **Source** to **GitHub Actions**.
3. Run **Publish CircuitBench web app** from the **Actions** tab. Future pushes to `main` rebuild and publish automatically. The deployment job displays the site URL.

Only the contents of `web/dist` are published. All runtime URLs are relative to the site and work under a repository subpath. npm is used during the build and visitors load assets from GitHub Pages.

## Use the workbench

- Use **Theme** to switch between light, dark, and your system setting. The browser remembers your preference.
- Start with the 10 V divider or choose the RC AC and transient examples. Use **Profile settings** to edit the analysis and **New profile** to create a DC source sweep.
- Operating-point runs label the schematic with node voltages and signed current directions. The **Readings** panel lists the same values, and **Show plot** opens the optional plot for operating-point and DC sweep results.
- Open or download a desktop-compatible `.cwb` schematic. Use **Import models** for SPICE model cards and the supported self-contained subcircuit subset, or load the included Qucs-S and starter libraries.
- Place components with the library, wire grid points, add junctions and attach voltage, differential or pin-current markers. The selection tool supports shift selection, drag, and arrow-key movement. Scroll to zoom and middle-drag, right-drag or Alt-drag to pan.
- Results support plot pages, subplots, trace expressions, labels, axis settings, pins, CSV and PNG. Use **Print page / PDF** and the browser's PDF destination to export a PDF.
- **Run history** keeps snapshots, decks, logs and ASCII waveform files in browser storage. **Run files** downloads them individually. Clearing site data clears this history.

The desktop uses ngspice 47. The pinned browser engine uses ngspice 46 and its built-in device models. Windows binaries, including native OSDI and XSPICE modules, cannot be loaded into this browser build. The browser can open the ASCII raw files generated by CircuitBench.
