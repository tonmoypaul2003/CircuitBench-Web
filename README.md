# CircuitBench Web

A browser-based schematic editor and ngspice simulator. Run operating-point, AC, transient, and DC sweep analyses locally in your browser.

[Open CircuitBench Web](https://tonmoypaul2003.github.io/CircuitBench-Web/) · [Build and usage instructions](web/README.md) · [Desktop project](https://github.com/tonmoypaul2003/CircuitBench)

On Windows, double-click `web/Start CircuitBench.cmd` to preview locally with Node.js installed.
